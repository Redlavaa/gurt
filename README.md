# gurt bot
> [!WARNING]
> This bot is in very early alpha. Expect things to be broken or missing.

Gurt is a discord bot created for polytoria. The bot uses polytorias api to get information.
# How to use
Install modules
```shell
  pip install -r requirements.txt
```
Create a .env file in the root directory and put this in it along with your discord token
```
  TOKEN='TOKEN HERE'
```
Launch the bot
```shell
  py main.py
```
