# gurt bot
Gurt bot is a discord bot that lets you fetch polytoria info, the way I made this bot is one of the only ways to get information because of the current state of the servers.
# How to use on Windows
create a web browser
```powershell
  "PUT WEBBROWSER EXE FILEPATH HERE" --remote-debugging-port=9222 --user-data-dir="C:\PUT WHERE YOU WANT TO CACHE YOUR BRAVE FILES HERE" --new-window
```
install required modules
```python
  pip install requirtments.txt
```
run main.py to start the program (PUT TOKEN IN THE TOKEN VARIABLE IN MAIN.PY FIRST!!!)
```python
  python main.py
```
# How to use on Linux

create a web browser, make sure to change the remote config thing
```bash
/usr/bin/browserhere --remote-debugging-port=9222 --user-data-dir="/home/yourusername/.config/browser-remote" --new-window
```
install required modules
```python
  pip install requirtments.txt
```
run main.py to start the program (PUT TOKEN IN THE TOKEN VARIABLE IN MAIN.PY FIRST!!!)
```python
  python main.py
```
